# مرکز انتشار PHP 8.3 برای دیجی‌بایل

این بسته برای افزودن مدیریت نسخه به برنامه PHP 8.3 و MariaDB موجود طراحی شده است. این بسته جایگزین برنامه فعلی نیست و دیتابیس یا مسیر تولیدی را تغییر نمی‌دهد.

## معماری انتشار

1. تغییرات در GitHub ثبت می‌شوند.
2. پس از تأیید تست‌ها، یک Release با نسخه معنایی (مانند 1.2.0) و فایل manifest منتشر می‌شود.
3. سرور فقط manifest و بسته همان Release را از مخزن معتبر دریافت می‌کند.
4. مدیر در پنل، نسخه، شرح تغییرات، نوع امنیتی/عادی و سازگاری PHP/DB را می‌بیند.
5. پیش از نصب، فایل‌ها و دیتابیس پشتیبان‌گیری و checksum بسته بررسی می‌شود.
6. مهاجرت‌های SQL به ترتیب و با ثبت شناسه اجرا می‌شوند. فقط migration افزایشی مجاز است.
7. پس از نصب، health check اجرا می‌شود؛ در شکست، فایل‌ها از پشتیبان برمی‌گردند و برای DB فقط rollback صریح و آزموده‌شده اجرا می‌شود.

## وضعیت این مخزن

شاخه پایه `refactor/digibail-mariadb-only-20261031` برنامه Node.js/Next.js با درایور MariaDB است، نه کد PHP. فایل‌های PHP واقعی برنامه دامنه در این شاخه موجود نیستند. بنابراین این بسته فعلاً قرارداد و طرح SQL را فراهم می‌کند؛ اتصال صفحه به احراز هویت مدیر، تنظیمات PDO، مسیر نصب و فرمان deploy نباید حدس زده شوند.

## موارد لازم برای اتصال نهایی

- کد PHP واقعی برنامه و نقطه ورود پنل مدیریت.
- روش احراز هویت و نام/ساختار session مدیرکل.
- مسیر دقیق document root و مسیر امن خارج از public_html برای backup.
- مجوز SSH/Deploy key در GitHub Actions و کلید عمومی متناظر در سرور.

هیچ رمز، کلید خصوصی یا مقدار محرمانه‌ای نباید در Git ثبت شود.
