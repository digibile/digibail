# DigitalPay / Digibail Pay

این شاخه بسته‌ی افزونه‌ای DigitalPay را برای اتصال به پروژه‌ی میزبان Ghestine نگه می‌دارد.

## وضعیت مهم

- این مخزن به‌تنهایی پروژه‌ی میزبان کامل ASP.NET را در بر ندارد؛ کدهای پایه‌ی دامنه، برنامه، زیرساخت و API میزبان باید جداگانه در دسترس باشند.
- فایل‌های SQL این بسته ساختار ماژول‌های افزوده را فراهم می‌کنند و جایگزین دیتابیس یا داده‌های قبلی سامانه نیستند.
- Workflow این شاخه فقط اعتبارسنجی اولیه‌ی فایل‌های ضروری و نحو اسکریپت‌های Bash را انجام می‌دهد. سبز شدن این بررسی به معنی کامپایل، تست یکپارچه، اتصال واقعی پیامک/بانک، یا آماده‌بودن برای تولید نیست.
- استقرار روی سرور، ساخت دیتابیس عملیاتی، ایجاد حساب مدیرکل و تنظیم پراکسی در این مرحله انجام نمی‌شود.

## اجرای CI

از زبانه‌ی **Actions**، گردش‌کار **DigitalPay CI** را باز کنید. خطاها یا هشدارهای مربوط به نبود پروژه‌ی میزبان را قبل از استقرار بررسی کنید.
