# دیجی‌بایل | پیش‌نمایش GitHub

این شاخه یک **سرور پیش‌نمایش فرانت‌اند** برای بررسی صفحات موجود مخزن فراهم می‌کند. این راه‌اندازی برای تست GitHub Actions و ساخت تصویر Docker است و به‌تنهایی محصول کامل یا بک‌اند عملیاتی نیست.

## صفحات

| مسیر | فایل |
| --- | --- |
| `/` و `/index.html` | `web/template-v3.html` |
| `/login.html` | `frontend/login.html` |
| `/register.html` | `frontend/register.html` |
| `/documents.html` | `web/documents.html` |
| `/contracts.html` | `web/contracts.html` |
| `/panel.html` | `backend/core/panel.html` |
| `/healthz` | وضعیت سلامت به شکل JSON |

## اجرا در محیط توسعه

نیازمندی: Node.js نسخه 22 یا جدیدتر.

```sh
npm test
PORT=1631 HOST=127.0.0.1 npm start
```

سپس مسیر `http://127.0.0.1:1631/` را باز کنید. برای بررسی سلامت، `http://127.0.0.1:1631/healthz` را بخوانید.

## ساخت و اجرای Docker

```sh
docker build -t digibail-preview .
docker run --rm -p 1631:1631 digibail-preview
```

## بررسی خودکار

Workflow در GitHub Actions فایل‌های ضروری، نحو اسکریپت‌های shell، JSON نمونه، تست‌های مسیر، پاسخ‌های HTTP روی پورت 1631 و ساخت Docker image را بررسی می‌کند.

## محدودیت‌های مهم

- این سرور فقط فایل‌های HTML مشخص‌شده را نمایش می‌دهد؛ API واقعی را پیاده‌سازی نمی‌کند.
- درخواست‌های `/api/*` پاسخ `501 backend_not_included` می‌گیرند تا با پاسخ جعلی یا شبیه‌سازی‌شده اشتباه نشوند.
- صفحه ورود، ثبت‌نام، مدارک، قراردادها و پنل برای کارکرد عملیاتی به بک‌اند واقعی، تنظیمات و اتصال پایگاه داده نیاز دارند.
- در این مخزن، پروژه کامل قابل ساخت .NET (`.sln` و `.csproj`) هنوز تأیید نشده است؛ اسکریپت‌ها و قطعات کد C# به‌تنهایی اثبات کامپایل‌پذیری نیستند.
- هیچ استقرار یا تغییری روی سرور واقعی در این شاخه انجام نمی‌شود. GitHub Actions فقط محیط موقت CI را اجرا می‌کند.
- پورت `1631` در این تنظیم برای اجرای پیش‌نمایش است؛ باز کردن پورت روی سرور یا تنظیم reverse proxy مرحله جداگانه‌ای است.
